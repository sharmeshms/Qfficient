# Known Issues & Audit Registry

This document tracks known bugs, mathematical discrepancies, and architectural issues discovered during system auditing, along with their severity, affected files, resolution history, and defined project scope boundaries.

## Discovered Issues & Resolution History

| Issue ID | Severity | File(s) | Description | Status |
| :--- | :--- | :--- | :--- | :--- |
| **ISSUE-01** | High | `pipeline.py`, `grid_engine/ieee_feeder_loader.py`, `solvers/exact_classical_solver.py` | 12-component microgrid lacked tie lines; default baseline took lines 0..10 creating 4 disconnected islands with zero loss, leading to division by zero and astronomical negative percentages (-42B%). | **Resolved (Phase 1A)**: Designated tie switches `{1, 2, 10, 12, 14}` producing a connected radial baseline (8.22 kW loss). | **ISSUE-02** | High | `qubo_engine/qubo_builder.py`, `solvers/openjij_annealer.py` | 5 fundamental co-tree cycles admit 159,964 zero-penalty configurations out of $C(37, 32) = 435,897$, of which 68.27% are invalid non-tree subgraphs. | **Resolved (Phase 1B)**: Added `cycle_mode="elementary"` with binary slack variables spanning all 26 elementary cycles (100% valid trees). Added Kruskal loop repair and explicit attribution modes (`raw`, `marginal_mst`, `filtered`). |
| **ISSUE-03** | Medium | `verification/fast_flow.py` | AC DistFlow branch loss feedback was omitted in earlier revisions, causing a 2.4% power loss discrepancy relative to exact AC reference solvers. | **Resolved (Phase 1C)**: Implemented exact Baran-Wu AC DistFlow with branch loss feedback.
